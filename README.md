# Tic-Tac-Toe AI

A rule-based artificial intelligence that plays tic-tac-toe using strategic decision-making.

# Overview
This project implements a simple but effective AI for tic-tac-toe. The AI uses a priority-based strategy to make smart moves without machine learning.

# How It Works
The AI follows a strategic priority system:

- Win: Takes winning moves when available
- Block: Prevents opponent from winning
- Center: Occupies the center square (strongest position)
- Corners: Takes corner squares (second-best positions)
- Sides: Takes side squares as a last resort
